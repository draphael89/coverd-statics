# Coverd Packs: static ad images

Finished ad images and the product feeds that the catalogs read: `catalog.csv` (Meta) and `tiktok.csv` (TikTok, with the 9:16 images in `images_v/`). Built by `tools/static_catalog.py` in the private source repository; do not edit by hand.

Each picture shows a chase card of the pack it names. Pulls vary. Odds and terms apply.
